# Proyecto APT122 - Inteligencia de Mercado

Repositorio correspondiente al proyecto APT122 de Ingeniería en Informática.

## Descripción

El proyecto busca desarrollar y mejorar una solución de inteligencia de mercado orientada a la recopilación, procesamiento y visualización de información relevante para apoyar la toma de decisiones.

La solución considera el uso de tecnologías como desarrollo web, servicios backend, bases de datos, automatización, agentes de inteligencia artificial y análisis de información.

## Organización del repositorio

El repositorio se encuentra organizado por fases del proyecto:

- Documentación de definición y planificación

### Fase 2

## Metodología de trabajo

El proyecto se desarrolla utilizando metodología Scrum.

La planificación contempla:

- 18 semanas de trabajo
- 9 sprints de 2 semanas
- 3 releases incrementales
